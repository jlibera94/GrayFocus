# GrayFocus Privacy Policy

GrayFocus applies a grayscale effect to websites when the user enables it. This policy describes the information the extension processes.

## Information processed

GrayFocus reads the hostname of the current website so it can associate the user's grayscale setting with that site. It stores the hostname and the corresponding on/off preference in Chrome's local extension storage.

GrayFocus does not read or collect page text, form input, or other website content. It does not transmit hostnames or preferences to a server. It does not use analytics or advertising, and it does not sell or share information with third parties.

## Permissions

Website access is used to check the locally saved preference and apply the grayscale effect on websites where the user has enabled it. The active-tab and scripting permissions are used to apply the user's selection to the current tab from the toolbar popup. Storage is used only for site preferences.

## Retention and deletion

Preferences remain in Chrome's local extension storage until the extension data is cleared or the extension is removed. GrayFocus has no server-side copy of this information.

## Changes

This policy may be updated if GrayFocus's behavior changes. The date of the latest update will be reflected in the published policy.
